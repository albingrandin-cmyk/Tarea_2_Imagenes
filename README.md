# Tarea_2_Imagenes
Sourcecode for adaptive filtration and anisotropic diffusion

## Requirements
* Python 3.x
* `numpy`, `scipy`, `matplotlib`

## How the code is run
* `python task1.py` - Simulations and generates figures and prints results for pregunta 1
* `python task2.py` - Run anisotropix diffusion (TV, High-order, Laplacian) and generates figures and prints for pregunta 2
